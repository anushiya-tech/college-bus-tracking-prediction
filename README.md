# 🚌 College Bus Tracking & Prediction System

A modern and responsive **static web application** designed to make college transportation smarter and easier to manage.

### ✨ Features

* 🚌 **Bus Tracking** – View simulated live bus locations
* 🗺️ **Routes & Stops** – Explore available routes and stops
* ⏱️ **ETA Prediction** – Check estimated bus arrival times
* 🔔 **Notifications** – Get bus delay and arrival updates
* 📊 **Dashboard** – Monitor bus and route information
* 📱 **Responsive Design** – Works across desktop, tablet, and mobile

### 🛠️ Tech Stack

**HTML5 | CSS3 | JavaScript | Bootstrap 5**

### 🎨 Highlights

* Modern red-themed UI/UX
* Clean and user-friendly interface
* Interactive dashboard
* Responsive layout
* Simulated GPS tracking
* Frontend-based ETA prediction

### 📌 Project Status

**Frontend Prototype**

The current version uses **simulated data** for bus tracking and ETA prediction. It can be extended in the future with real GPS, backend services, databases, and machine learning.

### 🚀 Future Scope

**Real GPS Tracking • ML-Based ETA Prediction • Backend Integration • Mobile Application • IoT Integration**
