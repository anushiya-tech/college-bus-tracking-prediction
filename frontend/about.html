Project overview

About this project

This is a static frontend project for a college presentation. The system simulates bus tracking, route browsing, ETA prediction, and transport notifications using only HTML, CSS, JavaScript, and Bootstrap 5.

No backend, database, authentication, or real GPS integration is used. All values are fictional demo data.
What it demonstrates
  • Responsive navigation
  • Bus filtering
  • Route timelines
  • Prediction simulation
UI patterns used
  • Cards and badges
  • Forms and tables
  • Alerts and toasts
  • Progress bars and modals

Implementation Notes

Shared data lives in JavaScript
Buses, routes, and notifications are defined once and reused across pages.
Page-specific scripts wire interactions
Search, filter, prediction, and notification actions run entirely in the browser.
Bootstrap 5 handles layout and components
Responsive grid, navbar, forms, alerts, badges, and toasts are all Bootstrap-based.
Presentation-ready visual design
Blue-and-white transport theme with subtle motion and consistent spacing.
